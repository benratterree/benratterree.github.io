Arduino Pool Equipment Controller

June–July 2025. Project completed and tested. Ran without flaws for at least 12 months

Overview

The official Pentair acid pump controller had burned out twice before on our pool due to an undersized wire carrying more current than it should have and instead of buying a 3rd $300 controller I built a full controller for under $60. This Arduino controller communicates with Pentair pool equipment, doses acid (for balancing pool pH) on a set schedule, and runs safety checks against the other pool equipment.

How it works

  • Arduino-based controller
  • Communicates with Pentair pool equipment
  • Pumps acid on a set time interval
  • Safety checks with the other pool equipment

Challenges

The hardest part of this project was figuring out the Pentair communications protocol by reading the datastream and associating bytes with specific pool equipment commands or status updates. The Pentair communication protocol is not public and is only partially available on internet forums. This meant that I had to take a raw 9600 Baud output and read the outputs and find patterns in the data or associate specific messages with known events (turning the pool lights on or off). Eventually I was able to figure out the command for turning on and off the filter pump and I was able to read the status of the pool. Knowing the commands the code was fairly easy and it would run on an adjustable timer while the pool’s filter pump was on.
